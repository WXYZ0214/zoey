# 🎀 萌萌紙娃娃換裝秀 (Cute Chibi Paper Doll & Makeup Studio)

專為可愛角色換裝、精緻化妝與自由穿搭打造的現代化網頁紙娃娃遊戲！採用 **第 1 款：日系粉彩 Q 版 (Pastel Chibi Kawaii)** 風格，以純向量（SVG）高解析度分層渲染，無論放大縮小都能保持極致細膩與平滑線條。

---

## 🌟 遊戲核心特色功能

### 1. 💄 精緻化妝與五官系統
- **膚色切換**：粉嫩白皙、自然象牙、溫暖蜜桃、健康小麥、焦糖暖棕、夢幻粉紫、精靈薄荷，亦可自由拾色！
- **星眸大眼與瞳色**：水汪汪星眸、溫柔下垂眼、傲嬌貓咪眼，搭配 8 款寶石瞳色。
- **眉毛造型**：溫柔自然眉、韓系一字眉、俏皮弧度眉。
- **腮紅多樣化**：圓圓蘋果肌、軟萌雙愛心、動漫害羞斜線 (///)、微醺曬傷鼻橋，可自訂腮紅色調。
- **立體唇彩與表情**：淺淺微笑、開朗燦笑、可愛貓咪嘴 (:3)、嘟嘟嘴啾，多款水光唇彩調色盤。

### 2. 💇‍♀️ 夢幻髮型設計
- **前髮瀏海**：日系姬髮平瀏海、空氣感透氣瀏海、側分斜瀏海、內彎妹妹頭、氣質中分波浪。
- **後髮造型**：萌系雙馬尾、浪漫微捲長髮、俏麗波波短髮、元氣高單馬尾、雙球丸子頭、黑長直髮。
- **天使光環髮圈**：自帶日漫天使光環反光高光條，髮色隨心自選。

### 3. 👚 雙模式豐富衣櫥
- **分開搭配模式**：
  - 上衣：水手制服領衫、一字領荷葉露肩、軟萌麻花粗針織毛衣、潮流短版連帽衫、溫柔排扣小外套。
  - 下身：經典學院百褶裙、雙層荷葉蛋糕裙、俏麗反折牛仔短褲、粉彩街頭工裝長褲、英倫格紋百褶裙。
- **連身洋裝模式**：
  - 夢幻圍裙女僕裝、田園草莓泡泡洋裝、古典哥德束腰長裙、櫻花祭典和風浴衣。

### 4. 👠 精緻鞋襪與飾品
- **鞋履**：亮面瑪莉珍鞋、金扣厚底樂福鞋、粉彩輕便運動鞋、毛絨小熊室內拖、維多利亞繫帶短靴。
- **襪飾**：蕾絲花邊短襪、運動及膝條紋襪、經典過膝長筒襪、星芒透膚絲襪、裸足。
- **耳環配件**：璀璨星芒垂墜、溫潤珍珠耳墜、甜滋滋小草莓、時尚金屬大圈圈、愛心寶石耳釘、哥德十字吊飾。
- **頭飾配件**：軟萌大蝴蝶結、毛絨貓耳髮箍、圓滾小熊耳朵、荷葉女僕頭巾、文藝毛呢貝雷帽、星星彩色髮夾組、發光天使光環。
- **眼鏡面飾**：復古金絲圓框眼鏡、千禧粉紅愛心墨鏡。
- **頸飾與手持**：愛心寶石黑絲絨頸圈、典雅珍珠項鍊、金燦星芒細吊墜、軟萌兔兔布偶、黑糖珍珠厚鮮奶、夢幻魔法杖、粉彩拍立得相機。

### 5. 🌸 情境場景與動態特效
- **場景背板**：夢幻粉彩臥室、櫻花落瓣公園、甜蜜馬卡龍咖啡廳、璀璨星空幻夜、韓系拍貼機網美框、純透明底（去背貼圖模式）。
- **自然眨眼動態**：角色具備擬真呼吸眨眼動畫（可開關）。
- **漂浮閃亮星光**：周圍漂浮璀璨夢幻星芒粒子特效（可開關）。

### 6. 🎮 互動與工具
- **🎁 驚喜盲盒穿搭**：一鍵隨機搭配全身造型與繽紛彩帶紙片禮砲！
- **📸 拍照存檔 (HD)**：一鍵無損匯出 1000×1300 超高畫質透明底或含背景 PNG 圖片！
- **🔊 Web Audio 可愛音效**：內建合成可愛泡泡 Pop 聲、切換 Click 聲、快門喀嚓聲與魔法滑音，無需外連音檔！
- **📋 分享搭配代碼**：一鍵複製 JSON 配置，輕鬆保存分享。
